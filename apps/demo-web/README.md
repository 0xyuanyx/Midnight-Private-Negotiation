# Midnight Private Negotiation Demo Web

Buyer, Seller, Observer를 한 화면에 표시하는 발표용 웹 DApp입니다.

현재 버전은 Demo Controller의 WebSocket에서 정제된 `DemoEvent`를 받아 표시합니다.

```bash
npm install
npm run dev
npm test
```

## 실행 흐름

1. 각 패널의 로그 마지막 줄에서 동일한 네 자리 상품 코드를 입력합니다.
2. 코드 입력 줄은 사라지고 상단 상태 줄에 코드가 반영됩니다.
3. Buyer 최대 한도와 Seller 최소 금액도 같은 터미널 프롬프트에서 입력합니다.
4. 금액 입력 줄은 사라지고 자기 패널 상단에 잠긴 값으로 표시됩니다.
5. 한도가 겹치면 양쪽에 같은 시간의 공동 로그를 전달하고 증명과 `SETTLED` 흐름을 재생합니다.
6. 한도가 겹치지 않으면 내부적으로 최대 10라운드 후 금액 없이 `CANCELLED`로 끝납니다.

화면 로그에는 출처 태그를 표시하지 않습니다. Observer는 `거래 개시 · OPEN`,
`가격 조건 승인 · AUTHORIZED`, `거래 확정 · SETTLED` 또는
`거래 취소 · CANCELLED`처럼 한글 설명과 실제 공개 계약 상태를 함께 확인합니다.

협상 원문, 후보 가격, PolicyGuard 판정, 내부 라운드는 어떤 패널에도 표시하지 않습니다.
최대 10라운드는 종료를 보장하는 내부 안전장치일 뿐 `(1/10)` 형태의 진행 정보도
노출하지 않습니다. 상대 참여나 가격 커밋을 이미 확인한 경우 대기 문구를 생략하고
완료 로그를 바로 표시합니다.

색은 문장 전체가 아니라 의미 토큰에만 적용합니다. `비공개 협상`과
`금액 비공개`는 골드, 증명·`OPEN`·`AUTHORIZED`는 연보라,
합의·`거래 확정`·`SETTLED`·최종 금액은 세이지그린, 결렬은 적색입니다.
가격 커밋과 `로컬 비공개`가 반복되는 완료 문장은 흰색으로 유지합니다. 지갑 주소,
트랜잭션 해시, 블록 번호는 메인 3패널에 표시하지 않습니다.
